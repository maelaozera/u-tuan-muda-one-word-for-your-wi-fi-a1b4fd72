One word that describes Wi-Fi — the funniest and most accurate one — written to `/output/entry.txt` by a small TypeScript program.

> Teenager

## Run it

```sh
node main.ts
```

This writes the single-line entry to `/output/entry.txt` (creating `/output` if needed). The program is deterministic: every run writes the exact same bytes.

## The gate

The gate requires `/output/entry.txt` to be UTF-8 text of 1–20 characters, not only whitespace, exactly one word. This entry is 8 characters, so it passes.
